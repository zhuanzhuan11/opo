# OPO2.0新版一体化测试界面

2026-10-18最新：用户要求沿用原OPO2.0投资方演示界面做删减，先审核界面及功能，决定后再开发业务代码并存GitHub。本轮不开发生产后端或推送GitHub。

本页是本地交互测试，不是公网发布或真实资金功能。保留现有商城代码，在同一项目frontend和scripts目录新增测试界面，未改动既有资金API、客户数据库、域名解析及正式商品目录。

## 打开

在opo-2.0目录使用Node 24执行：

```text
node scripts/start-model-preview.mjs
```

功能展示入口：http://127.0.0.1:3211/model-review.html 。商城：http://127.0.0.1:3211 。后台定价界面原型：http://127.0.0.1:3211/admin-preview.html 。默认只监听本机；不是可供其他手机直接访问的公网地址。结束时在运行终端按Ctrl+C。可通过OPO_PREVIEW_PORT选择其他本机端口。独立预览服务器只允许指定界面文件，不提供数据库、注册、支付或后台接口。

## 可以操作

- 商城首页、六款沿用原图的示意商品、搜索、结算、消费积分最高50%抵扣、模拟普通支付/Binance Pay/钱包支付、订单及一次性退款。
- 50USDT起模拟认购，按0.01计价对应ZC，模拟锁定销毁，不返还ZC；取得固定两倍消费积分，一年释放。按批次、测试时间和微单位累计计算；OPOC不兑USDT或ZC。
- LP模拟质押、推进时间、退出；奖励只按实际参与时段的份额分配，退出保留已累计奖励。当前LP数量为浮点近似的界面模拟，正式合约须采用整数累计和尾差规则。节点模拟领取，节点及LP仍三年。
- 全部成本录入、2.5至3倍率、向上取整到分、后台报价预览、最高积分抵扣后现金收入及减成本结余；不发布商品或改变前台价格。定价只在独立管理后台原型，不在前台菜单，直接#pricing也不显示工作台。原型未实现真实鉴权，没有敏感成本资料；正式开发时必须管理员服务端鉴权/MFA，白名单及城市服务商暂不开放。测试默认倍率2.75；8类费用包括采购/物流/包装/税费/售后/运营/支付/获客，真实项目还应补齐任何未覆盖的实际成本。
- 一键兑换USDT按钮：说明外部流程后，可进入币安官方P2P页面。不会创建币安订单、付款、查询其资金账户，返回商城不会自动增加余额。
- 浏览器支持EIP-1193钱包时，可由用户主动连接，只读BSC链ID、区块、钱包地址、USDT/ZC和BNB余额。无签名、转账、approve或burn调用。未安装钱包或网络不符时提示，不自动添加或切换网络。

## 客户ID与余额

余额会变化、多人也可以相同，不能作为客户ID。测试界面保留OPO-DEMO-001客户号，钱包关联标识使用eip155:56:地址；只有地址及只读余额不构成已验证登录。真实账号绑定仍需服务端随机nonce签名、防重放、原账号关联和恢复流程。现有会员及邀请码不因打开测试界面而改变。

链上余额与页面测试现金/积分分开显示，不能拿真实余额在此扣款；币安Funding/Spot/Pay余额也不能由链上地址推导。读取余额全部通过用户钱包提供者，不把地址发送给本站后台或外部统计服务。

## 测试数据

本页只有示意商品与合成账户，默认250模拟USDT和一批100 OPOC权益，测试时间为该批开始后第180天。所有模拟状态只在页面内存，刷新/重置即消失；不是已锁仓证明、真实销毁记录、成交/付款或持久订单。不把示意商品加入正式目录。

浏览器验证使用模拟钱包，不连接用户真实钱包，不打开外部币安页面或发送真实交易。通过UI测试不代表BSC主网/币安商户接入已验收。

## 正式接入仍需完成

1. 一套经过整合的后台订单、积分、库存及退款账本，服务端权威报价、权限和幂等；测试页面不能直接变成正式资金页面。
2. ZC真实burn/手续费能力、对应合约源码、库存、交易确认与重组恢复；认购和销毁失败补偿。
3. 币安Pay/其他支付商户准入、适用地区、接口密钥、创建订单、签名回调与主动查单、过期退款；普通银行卡/本地支付的真实服务商。不能把P2P跳转当成商城支付API。
4. 钱包所有权验证与账号安全绑定；手机扫码/WalletConnect类连接、Gas和多钱包选择尚未实现。
5. LP及节点真实合约、费用转换、回购和LP凭证权属；实际链上状态与积分/订单对账。
6. 真实商品成本、供货商结算、商家补贴、历史权益迁移和完整经营规则；当前新测试界面主要为中文，正式多语言内容需补齐，原三语展示页仍保留。

当前继续暂停部署和真实资金操作。产品入口可以统一，交易所登录/KYC/实际付款确认仍由相应服务执行；没有用户授权和官方可用接口不能代办。
