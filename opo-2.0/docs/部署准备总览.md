## 如何理解完成状态

- 已实现：代码存在并经过对应测试，不等于真实主机验收。
- 已准备待执行：模板/脚本/手册齐全，但尚未在正式环境运行。
- 待补资料：真实账号、商品、身份/规则或凭据缺失，助手不代造。
- 未实现：仍需开发，不伪装成只要填密钥就能使用。
- 首期阻塞：恢复部署前必须完成；后期阻塞：只阻塞相关资产功能，不阻塞已隔离的展示咨询版。

“本地部署前准备已整理”与“所有生产条件已满足”是不同结论。没有Docker/Caddy或正式服务器时，不能把相应检查写为通过；最终域名、HTTPS、权限、异地恢复、告警和真实咨询仍要在恢复部署后验收。
