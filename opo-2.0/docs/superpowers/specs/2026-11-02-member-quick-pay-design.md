# 会员快捷支付工作台设计

日期：2026-11-02
范围：OPO 会员快捷支付前端模拟工作台；不启用真实收款、Wise 接口、钱包连接或链上转账。

## 目标

将快捷支付从现有“独立多商户积分原型”扩展为可审查的会员商业共享工作台，覆盖商户申请、会员 ID、收银确认、积分跨店消费、USDT 备用金展示、退款、授权代操作和中日英语言切换。首页解释参与价值：商家提升客户黏性，让消费者转变为建设者，连接行业商家客户，形成 OPO 商业平台共建共享；商户会员可获得商品消费返利，分享可获得私域流量变现收益，积分可在参与 OPO 的商家间使用。

## 入口与页面结构

新增独立页面 `member-pay-workbench.html`，在 OPO 商城现有侧栏加入该工作台入口。本地预览服务器增加该页面及其静态资源允许项。现有 `member-pay-all.html` 与历史单店 `member-pay.html` 保留。

工作台顶部提供简中/日本語/English 切换与醒目的“演示模式”提示。主导航包含：

1. 首页 / 为什么使用：面向商家、消费者和 OPO 商业平台的价值说明与核心流程。
2. 商户申请：商户名称、营业/收款方式、接受币种、BSC 钱包地址、消费省与分享赚比例、备用金额度；申请后为待审核，批准后才开放收银。接受币种决定积分名称（JPY、YUAN 或对应币种代码）。
3. 会员 ID：模拟注册与会员积分总览，按积分币种和来源显示；允许设置客户确认支付或向商户授予/撤销代确认权限。
4. 收银台：选择已批准商户、会员、账单金额和现有收款渠道；登记“商户已在原收银渠道收款”，再生成待确认记录。客户优先在 OPO ID 中确认；有代操作授权时允许商家代确认并留下操作人记录。确认后按商户设定比例记积分并冻结对应模拟 USDT 备用金。
5. 积分与退款：积分按币种命名，1 积分对应该币种 1 单位的购买力；参与商家间通用，消费扣减。全额或部分退款会冲销关联积分，并模拟释放对应冻结备用金。对已消费奖励的退款追偿以模拟冲回为限，界面注明正式规则待确认。
6. 备用金与钱包：展示模拟钱包地址、USDT 总额/冻结额/可用额、每日最高发分估值与 1.5 倍储备参考；初始金额不得低于 100 USDT。商户可按交易额自设额度；退出申请展示可退额度，先提示未结积分和待结算责任。
7. 交易与责任记录：显示商户收款确认、客户/受托商户操作人、积分发放/抵扣/退款、跨店补偿和备用金变更记录。

## 模拟数据与计算规则

- 浏览器本地内存模拟，刷新后重置；使用虚构演示商户与虚构 BSC 地址，不要求输入真实资料。
- 货币兑换率 UI 使用“Wise 实时汇率接入位 / 当前为演示报价”标签。当前不请求 Wise，不可标称实时或真实冻结。USDT 金额以演示报价将积分本币面额折算成美元等值后累计冻结。
- 商户积分按接受币种记账，例如日元商户发 `JPY`，人民币商户发 `YUAN`。跨商户按目标账单币种对现有积分作演示汇率折算；每笔记录显示原积分、核销账单币种等值和模拟汇率。小数精度服从币种。
- 先复用商户现有收银方式。OPO 只模拟收款后确认/发积分，不调用微信、银行卡、PayPal 等机构。
- `消费省` 发给消费者；`分享赚` 发给会员选择的直接推荐人。比例商户自行设置，不能使两者合计超过 100%。
- 新商户申请审核状态与会员支付授权是两个不同状态；只有审核通过且模拟备用金达到要求的商户可新增成交。该演示中的审核按钮不会连接后台。
- 模拟退款按订单奖励 lot 反向冲销，并释放相应预留；若奖励已经被消费，则形成待追偿提示，不伪装为已完成真实退款或资金划拨。
- 所有资金、钱包、商户审批、备用金冻结/返还均保持模拟；无助记词、私钥输入框，无真实转账按钮。

## 多语言和无障碍

所有菜单、表单标签、说明、帮助、提示、表格列名、空状态、确认弹窗和操作反馈均纳入 `zh-CN`、`ja`、`en` 翻译字典。语言切换即时刷新，不依赖服务器；表单和所选工作区状态应尽量保留。按钮使用明确动作文本，状态通过文字而非颜色单独表达；支持键盘聚焦与窄屏布局。

## 本轮验收边界

- 用户能在本地浏览器打开新工作台，查看首页价值说明并切换中/日/英。
- 能演示商户申请、批准、会员注册、商户原渠道收款登记、客户确认或受托商户确认、积分发行与跨店核销、退款、备用金视图和责任记录。
- 刷新后演示数据可重置；页面清楚标注所有金额为模拟数据，没有真实收款、Wise 汇率请求或链上操作。
- 打开主商城的快捷支付入口仍可进入新工作台；旧原型 URL 保持可用。
- 先交给用户审查本地界面；没有通过前不推送 GitHub、不发布外部站点。

## 待生产化决策

正式接入前需另行确定：Wise 产品/API 与报价时效、费率和地域资格；BSC 合约/托管或商户自托管方案及密钥管理；USDT 资产所有权与破产隔离；汇率波动和网络费责任；积分法律属性、退款后已消费奖励的追偿、商户退出结算窗口；商户准入/KYC/制裁筛查；客户个人数据和代理授权撤销/限额；跨币种兑换精度、舍入和定价争议处理。上述事项不会由本次纯前端模拟擅自定为真实业务规则。
