## 文档优先级与历史

先读最新开发同步，再按模块查代码、配置和测试。若它们冲突，必须列出差异并确认，不能用旧文档覆盖新规则。PROJECT_MEMORY.md、当前版本交接.md、版本25交付、历史PDF和根目录1.0说明均为历史追溯资料，不自动代表最新状态；不删除，不新增个人或内部会话内容到这些公开文件。

新增公开开发文档必须在本索引登记。版本快照写清版本和日期；不要让多个文件同时自称“唯一最新”。
