# OPO 2.0 上线核查与剩余条件

核查日期：2026-10-17；版本：2.0.0-preview.2；源码基线：88e17205b082841aedeebb44f14dc1c140ba5e7a。

## 结论

当前是经过加固的开发预览，**不具备接收真实资金的全部条件**。不要删除正式启动限制，不要充值。已有测试证明的是相应本地预览流程，不证明链上交易或生产可用性。

## 本次实际修复

- 修复商家作为买家时可能跨店发货的权限问题；撤销商家资格时回收商家角色。
- 未发货订单全额退款恢复库存一次；已发货退款不自动把未退回实物算入库存。
- 可调整直推、间推、回购、LP、平台、持币奖励和两级释放加速比例；原默认比例保留。100 个基点等于 1%；分账六项合计不超过 100%，加速不作为额外现金分账。
- 参数变更走提案、另一管理员复核、发布流程，拒绝自己批准、重复批准及过期规则版本；旧订单保存原规则。
- 积分按商品行比例及最大余数法分配，每行不超过一半，订单记录分配算法版本。
- 服务端生成一分钟有效报价，绑定用户、购物车和规则版本；库存数量波动由下单时的原子库存检查处理。
- 管理员动态验证码绑定、加密保存、登录验证、防重放及其他会话失效；支持独立密钥文件。未配置时不能绑定，不会伪装成已启用。
- 登录账户/IP限流持久化、会话及报价清理、HTTPS安全头、来源配置校验。
- 数据库按迁移版本升级，拒绝未知较新版本；补充查询索引及数据库文件权限。
- 内部准备金、订单托管、归属库存对账；一致性备份、校验摘要及隔离副本恢复检查。
- 增加持续检查工作流、Docker最小权限配置、上线检查命令及只读链上核验脚本。

## 已执行验证

验证命令和最新输出见本地 test-results。代码回归覆盖资金上限、退款、商家隔离、参数快照、双人复核、MFA、报价、备份恢复及启动限制。浏览器覆盖中英日三语、360px和1440px布局、购物结算、发货收货、规则复核和MFA绑定。平台为本地 Windows/Chrome，未验证 macOS/Safari。

本地合成压力场景为1000商品、100独立会话、100并发商品查询及10并发下单；使用内存SQLite和本机HTTP，不能用作正式主机容量、真实磁盘或区块链延迟验收。

## 真实链上观察

从原开发资料发现候选ZC地址 0x231bde6480345804679882c8349497a3eeba7905；它不是本次新确认的生产配置。

2026-10-17通过BNB Chain文档所列主网RPC进行了单节点只读查询：链ID56，有合约代码，decimals返回18；常见EIP-1967 implementation/admin/beacon槽均为零，owner调用不可用。**这不能证明不可升级、无管理员或安全**，自定义代理及其他权限必须检查源码。链上18位与预览ZC六位精度不同，新增工具只提供精确换算并拒绝静默截断，尚未接通真实资产。
