# ENI 旧链 USDT 承接演练与真实接入清单

## 当前演练规则

- 测试输入为会员 ID、旧链交易参考号、演示到账金额和手动填写的 ZC 参考价；默认示例为 `ENI-DEMO-0001`、`DEMO-ENI-TX-0001`、1,000 USDT、1 USDT/ZC。
- 只有在真实系统确认收款后，才应按“核验到账 USDT ÷ 核准的 ZC/USDT 价格”计算等值 ZC。本地页面仅试算；示例数值为 1,000 ZC，不代表执行了销毁。
- 权益额度按到账 USDT 的 1.5 倍计价。示例为 1,500 USDT 计价的 OPOC 权益，365 天逐日释放。页面中的金额是 USDT 计价权益，不是已确定的 OPOC 代币枚数；代币单位和兑换关系尚未定义。
- 演练不会连接 ENI 链、生成收款地址、写入客户余额、转账、销毁 ZC、铸造或发放 OPOC。刷新页面后演练输入及结果不作为持久账务记录。

## 真实接入前必须确定

1. **旧 ENI 链识别**：正式网络名称与 Chain ID、USDT 合约地址及精度、节点/RPC 来源、交易确认数、重组和异常交易处理规则。
2. **收款与控制权**：正式收款地址由谁控制、资金归属及对账流程、地址轮换方案、私钥/HSM 托管和审批制度；严禁在前端保存私钥或助记词。
3. **到账核验**：服务器端监听和独立复核转账事件；使用链 ID、交易哈希、日志序号等唯一键防重复；处理错误链/币种、少付、多付、重复、退款、回滚及账户绑定争议。
4. **会员绑定**：真实会员 ID 创建和认证、钱包地址所有权证明、一个地址能否更换/绑定多个会员、人工复核及申诉流程。
5. **ZC 定价和销毁**：认可的 ZC/USDT 价格来源、取价时间、滑点与异常报价处理；实际销毁方式、销毁地址/合约、链上事件及独立对账。转入不可用地址不应未经验证就称为销毁。
6. **OPOC 计价与账本**：明确 1,500 USDT 计价权益如何换算为 OPOC 枚数、换算价格和锁定时点、精度及舍入规则；明确总量上限、发放权限、余额账本、幂等流水和更正/撤销机制。
7. **365 天释放定义**：明确起算事件、首日是否释放、时区、每日释放时点、闰日规则和中途退款/纠错处理。本地演练按确认起算日的第 1 至第 365 天线性逐日分配，最后一天补齐总额。
8. **运行与上线控制**：持久化数据库、最小权限后台、审计日志、密钥轮换、监控告警、备份恢复和故障演练；在这些条件及合规审查完成前，真实收款、销毁和发放必须保持关闭。

## 验收示例

在演练页输入 `ENI-DEMO-0001`、`DEMO-ENI-TX-0001`、`1,000`、ZC 价格 `1 USDT`：页面应显示模拟收到 1,000 USDT、试算等值 1,000 ZC、1,500 USDT 计价 OPOC 权益、365 天计划，并明确未连接旧链、未销毁、未记入客户余额。第 365 天累计计划达到 1,500；这些结果不是链上或客户账务凭证。
