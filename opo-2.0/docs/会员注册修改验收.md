# 首页会员注册与使用说明修改

日期：2026-10-18。仅本地修改，按用户要求暂不上线。

## 行为

- 首页新增会员注册、登录、退出和商城使用说明入口，中日英均提供对应内容。
- 注册填写会员账号、昵称、密码、邀请码并同意会员信息处理说明。密码要求12–128位，账号要求3–32位小写字母、数字或下划线。
- 沿用既有规则：会员账号就是邀请码。有效邀请码绑定对应会员；未填写或仅空白时服务端绑定商城专用邀请码opo；错误邀请码提示改正，不自动转绑。
- 平台邀请账户固定ID为opo-platform，不具备管理员权限且禁止登录。既有opo同名但不同ID账户触发启动冲突，避免误认真实会员或覆盖历史关系。
- 注册不创建订单或资金流水，不发放奖励，付款、充值和代币功能继续关闭。咨询仍独立于会员登录，不自动关联为会员订单。

## 修改文件

- backend/server.mjs：平台邀请账户、注册接口开放与默认绑定、会员同意校验；复用现有认证、限流、会话和来源校验。
- frontend/catalog.html、frontend/assets/catalog-members.js：注册登录表单、会员状态、三语使用说明。
- frontend/assets/catalog.css：手机入口布局及hidden元素显示修正。
- tests/catalog-members.test.mjs、tests/catalog.test.mjs：新增会员与权限测试，更新首期接口开放预期。
