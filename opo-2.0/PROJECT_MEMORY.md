## 最新界面与商品

- 沿用原OPO红白商城与三语；首页桌面上下各6款，中间七大分类好物分隔，13款完整目录覆盖7类。不能改回三列长列表导致两侧大空白。
- 前台不显示成本倍率，管理后台原型保留全部成本×2.5至3；后台原型不等于已鉴权后台。
- 新图是带OPO标识的AI摄影风格示意图，不是供货/实拍证据。产品仍标不在售，不编造SKU、库存、规格、物流、售后或授权。
- 商品图片/名称打开#product-ID详情页：主图、同图局部放大、下方页内付款；原快速购买弹窗保留。本轮无视频，未来视频不得超过30秒。
- OPOC支付数量自行填写，默认0、0.01精度，严格低于商品总价50%且不超过可用积分；49.50商品最多24.74 OPOC。订单/退款使用实际指定金额。
- 邀请码留空归平台opo1；会员ID独立于余额；钱包所有权正式签名认证未接入。
- OPOC支持商城消费及会员内部ID转账，只可转已释放未消费量，不能兑换USDT/ZC。模拟支持确认、双方记录和余额隔离。

## 经济模型与资格

- 私募认购ZC最终销毁，不返还ZC；按认购时价值固定2倍OPOC权益，一年释放，积分不可兑币。50USDT→5000ZC销毁→100OPOC总权益。
- LP奖励1亿ZC三年，按有效LP份额与时间；历史公链节点专项另留1亿，每1000USDT一份，三年本息合计1.5倍USDT等值ZC，按释放时价格折算，不接受新投资冒充历史节点。
- 指定BSC池卖出费20%=10%平台+10%换USDT配对LP预留ZC；买入/普通转账/奖励领取不收该卖出费。真实代币收税、burn、代理升级能力尚未核验。
- 城市专项三年总额50万USDT等值ZC，不是每日或每人额度；初始5000万ZC预留来自原LP预留，LP预留余5.49亿。不得占用会员USDT备用金。
- 一批旧客户通过消费1500人民币取得白名单，核定后在2.0保留资格，不要求补新门槛，不重新收资格费。其他历史费用说法需按批次核验，不能自动套用或折算积分。
- 旧白名单有效数量＝300基础权重＋本人实际已释放未消费OPOC；300是可随资格转让的入门权益，不是上限或可花积分。实际持有0/1000/5000，分别按300/1300/5300计权。
- 新白名单至少5000可用OPOC，服务商至少10000；以实际持有量计权，不另外赠300；不足时暂停相应新资格。旧身份不因不足新门槛失效。旧身份升级具体规则尚待确定。
- 分红时间权重＝各合格时段Σ（有效OPOC×合格持有小时）。个人累计权重/全体累计权重分配每日额度；余额、资格或转让变化分段。无资格时段不计，不把日终余额回套全天，不另加未确认的持有年限倍数。
- 资格转让只转资格及未来权益，300基础随旧资格转移；原余额及已获奖励不转。当前仅同页虚构历史资格可演示，原持有人资格取消，新持有人用自己的余额加300。新余额型资格转让仍待研发。
- ID标记：☆历史白名单、◇白名单、◆城市服务商。白名单商品上传仍需审核；服务商区域/权限及后续新增权益未定，不补造承诺。
